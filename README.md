# voice-typer

ქართული dictation Windows-ისთვის. დააჭირე ღილაკს, ილაპარაკე, ტექსტი გამოჩნდება იქ, სადაც
კურსორია — Claude-ის ჩატში, ბრაუზერში, Word-ში, ნებისმიერ პროგრამაში.

---

## რას აკეთებს

პროგრამა tray-ში ზის და ღილაკს უსმენს. **F9**-ს რომ დააჭერ, მიკროფონი ჩაირთვება; რომ
გაუშვებ, ჩანაწერი ElevenLabs Scribe v2-ს გადაეცემა და დაბრუნებული ქართული ტექსტი
ავტომატურად ჩაისმება აქტიურ ფანჯარაში.

ღილაკი ორნაირად მუშაობს:

| მოქმედება | შედეგი |
| --- | --- |
| **F9 დააჭირე და გეჭირე**, ილაპარაკე, გაუშვი | ჩაწერა იმ დროს, სანამ ღილაკი გეჭირავს |
| **F9 ერთხელ დააჭირე** (მოკლედ) | ჩაწერა იწყება და გრძელდება |
| **F9 კიდევ ერთხელ** | ჩაწერა ჩერდება, ტექსტი ჩნდება |
| **Esc ჩაწერისას** | უქმდება — არაფერი იგზავნება, არაფერი ჯდება |

tray-ის ხატულა გეუბნება რა ხდება: **ნაცრისფერი** — მზადაა · **წითელი** — იწერს ·
**ყვითელი** — გარდაქმნის · **მუქი წითელი** — შეცდომა.

## დაყენება

**1. ვირტუალური გარემო** — ყურადღება: 3.13, არა 3.14

```powershell
& "C:\Users\user\AppData\Local\Programs\Python\Python313\python.exe" -m venv .venv
```

**2. ბიბლიოთეკები**

```powershell
.venv\Scripts\python.exe -m pip install -r requirements.txt
```

**3. API გასაღები**

დააკოპირე `.env.example` და დაარქვი `.env`, შემდეგ ჩასვი შენი ElevenLabs-ის გასაღები:

```
ELEVENLABS_API_KEY=sk_...
```

გასაღები აქ არის: <https://elevenlabs.io/app/settings/api-keys>

**4. გაშვება**

```powershell
.venv\Scripts\pythonw.exe main.py
```

ან ორჯერ დააწკაპუნე `run.vbs`-ზე — კონსოლის ფანჯარას არ გახსნის.

## პარამეტრები

ყველაფერი `config.json`-შია, კოდის შეხების გარეშე:

| პარამეტრი | ნაგულისხმევი | რას ნიშნავს |
| --- | --- | --- |
| `hotkey` | `f9` | რომელი ღილაკი იწყებს ჩაწერას |
| `hold_threshold_ms` | `400` | ამაზე დიდხანს დაჭერა = „გეჭირავს", ნაკლები = „დააჭირე" |
| `max_recording_seconds` | `300` | ავტომატური გაჩერება, რომ ჩარჩენილმა ღილაკმა ფული არ დახარჯოს |
| `input_device` | `null` | მიკროფონი; `null` = სისტემის ნაგულისხმევი |
| `restore_clipboard` | `true` | ჩასმის შემდეგ ძველი clipboard დაბრუნდეს თუ არა |
| `language_code` | `kat` | ქართული, ფიქსირებული — ავტოამოცნობა მოკლე ფრაზებზე ცდება |
| `keyterms` | `[]` | სიტყვები, რომლებსაც ხშირად ამბობ და არასწორად იწერება — სახელები, ტერმინები |
| `prune_takes_after_days` | `7` | წარუმატებელი ჩანაწერები რამდენი დღის შემდეგ წაიშალოს |

### `keyterms` — სიზუსტის ერთადერთი ბერკეტი

თუ რომელიღაც სახელი ან ტერმინი მუდმივად არასწორად იწერება, ჩაამატე აქ:

```json
"keyterms": ["ნონიაშვილი", "ElevenLabs", "Claude Code"]
```

მაქსიმუმ 100 სიტყვა. მეტზე ElevenLabs ყოველ ჩანაწერს 20 წამად ითვლის და ფასი
რამდენჯერმე იზრდება — ამიტომ 100-ზე მეტი უარყოფილია გაშვებისთანავე, და არა ჩუმად მოჭრილი.

## რა უნდა იცოდე

**ხმა კომპიუტერს ტოვებს.** ჩანაწერი ElevenLabs-ს ეგზავნება ტრანსკრიფციისთვის — სწორედ
ამიტომ მუშაობს ქართული ასე კარგად.

**არაფერი იკარგება.** ყოველი ჩანაწერი დისკზე ინახება გაგზავნამდე (`logs\pending\`) და
იშლება მაშინ, როცა მისი ტექსტი უკვე ფანჯარაშია. თუ ინტერნეტი გაწყდა, პროგრამა ჩაკვდა ან
გამორთე შუა პროცესში — tray-ის მენიუში „ბოლო ჩანაწერის ხელახლა გაგზავნა" კვლავ იმუშავებს.
შეგიძლია მეორე წინადადება დაიწყო მაშინაც, როცა პირველი ჯერ იგზავნება — ერთმანეთს არ
გადააფარებენ.

**ტექსტი clipboard-ს გაივლის.** წამის მეასედში იქ იქნება, მერე ძველი შიგთავსი ბრუნდება.
სხვაგვარად ქართული ასოების ჩასმა ნებისმიერ პროგრამაში საიმედოდ არ გამოდის.

**ადმინისტრატორის უფლებით გაშვებული პროგრამები** ჩასმას არ მიიღებენ (Task Manager,
ზოგი ინსტალერი). ჩვეულებრივი პროგრამები და ბრაუზერები — ყველა მუშაობს.

**ტრანსკრიპტი ნედლია.** სასვენი ნიშნები ისეთია, როგორსაც Scribe აბრუნებს — დამატებითი
დამუშავება არ ხდება.

## თუ არ მუშაობს

`logs\voice_typer.log`-ში წერია რატომ. ხშირი მიზეზები:

| ხატულა | მიზეზი |
| --- | --- |
| მუქი წითელი, „no API key" | `.env` არ არსებობს ან გასაღები ცარიელია |
| მუქი წითელი, „401" | გასაღები არასწორია ან ამოიწურა |
| წითელი რჩება | მიკროფონი ვერ მოიძებნა — შეამოწმე `config.json`-ში `input_device` |
| ტექსტი არ ჩნდება, მაგრამ Ctrl+V მუშაობს | აქტიური პროგრამა ჩასმას ბლოკავს — სავარაუდოდ ადმინისტრატორით გაშვებულია |
| „ჩასმა ვერ მოხერხდა — ტექსტი logs საქაღალდეშია" | clipboard დაკავებულია სხვა პროგრამით; ტექსტი `logs\last_transcript.txt`-შია |
| „ტექსტად გარდაქმნა ვერ მოხერხდა" | ინტერნეტი ან გასაღები — ჩანაწერი შენახულია, გამოიყენე tray-ის „ხელახლა გაგზავნა" |
