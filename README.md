# voice-typer

ქართული dictation **Windows-ისა და macOS-ისთვის**. დააჭირე **F9**-ს, ილაპარაკე, ტექსტი
გამოჩნდება იქ, სადაც კურსორია — Claude-ის ჩატში, ბრაუზერში, Word-ში, ნებისმიერ პროგრამაში.

> *Georgian speech-to-text for Windows and macOS. Press F9, speak, and the transcript is
> pasted at the cursor in whatever window is focused. Powered by ElevenLabs Scribe v2.*

---

## რას აკეთებს

პროგრამა ეკრანზე პატარა ფანჯრად ზის და ღილაკს უსმენს. **F9**-ს რომ დააჭერ, მიკროფონი
ჩაირთვება; რომ გაუშვებ, ჩანაწერი ElevenLabs Scribe v2-ს გადაეცემა და დაბრუნებული ქართული
ტექსტი ავტომატურად ჩაისმება აქტიურ ფანჯარაში. 2-4 წამი სჭირდება.

ღილაკი ორნაირად მუშაობს:

| მოქმედება | შედეგი |
| --- | --- |
| **F9 დააჭირე და გეჭირე**, ილაპარაკე, გაუშვი | ჩაწერა იმ დროს, სანამ ღილაკი გეჭირავს |
| **F9 ერთხელ დააჭირე** (მოკლედ) | ჩაწერა იწყება და გრძელდება |
| **F9 კიდევ ერთხელ** | ჩაწერა ჩერდება, ტექსტი ჩნდება |
| **Esc ჩაწერისას** | უქმდება — არაფერი იგზავნება, არაფერი ჯდება |

## დაყენება

ორი გზაა. თუ უბრალოდ გინდა, რომ იმუშაოს — **პირველი**.

### გზა 1 — მზა პროგრამა (Python არ სჭირდება)

**Windows**

1. ჩამოტვირთე `voice-typer.exe`
2. დადე იმ საქაღალდეში, სადაც გინდა რომ იცხოვროს (მაგალითად `Documents\voice-typer`) —
   პარამეტრები, გასაღები და ლოგები მის გვერდით ჩაიწერება
3. ორჯერ დააწკაპუნე
4. პირველად ფანჯარა ითხოვს ElevenLabs-ის გასაღებს — ჩასვი და დააჭირე **შენახვა და გაშვება**

Windows SmartScreen შეიძლება გაფრთხილებას აჩვენოს („Windows protected your PC") —
ეს იმიტომ, რომ ფაილი ხელმოწერილი არაა. **More info → Run anyway**.

**macOS**

1. ჩამოტვირთე `voice-typer.app`, გადაათრიე `Applications`-ში
2. **პირველი გახსნა.** ორჯერ დაწკაპუნება არ იმუშავებს — აპლიკაცია Apple-ის ხელმოწერის
   გარეშეა. რა უნდა გააკეთო, macOS-ის ვერსიაზეა დამოკიდებული:

   | macOS | პირველი გახსნა |
   | --- | --- |
   | 14 (Sonoma) და უფრო ძველი | მარჯვენა ღილაკი აპლიკაციაზე → **Open** → ისევ **Open** |
   | 15 (Sequoia) და უფრო ახალი | დააწკაპუნე ჩვეულებრივად (macOS უარს იტყვის), მერე **System Settings → Privacy & Security**, ჩამოდი ქვემოთ და დააჭირე **Open Anyway** |

   Apple-მა 15-ში მარჯვენა ღილაკის გზა მოხსნა, ამიტომ ახალ Mac-ზე მხოლოდ მეორე ხაზი
   მუშაობს. ვერსიას ნახავ: **Apple menu → About This Mac**.
3. გასაღები იმავე ფანჯარაში იკითხება

macOS ითხოვს ორ ნებართვას, უამისოდ არაფერი იმუშავებს:

| ნებართვა | სად | უამისოდ |
| --- | --- | --- |
| **Accessibility** | System Settings → Privacy & Security → Accessibility | F9 საერთოდ არ მუშაობს და ტექსტი არ ჩაისმება |
| **Microphone** | System Settings → Privacy & Security → Microphone | ჩანაწერი მდუმარეა |

ნებართვის მიცემის შემდეგ აპლიკაცია დახურე და ხელახლა გახსენი.

### გზა 2 — კოდიდან გაშვება

დეველოპერისთვის, ან თუ exe არ გინდა. საჭიროა **Python 3.13** (3.14 არა — აუდიოსა და
კლავიატურის ბიბლიოთეკებს მისთვის ჯერ არ აქვთ გამოშვებული ვერსიები).

**Windows** — მარჯვენა ღილაკი `install.ps1`-ზე → *Run with PowerShell*, ან:

```powershell
powershell -ExecutionPolicy Bypass -File install.ps1
```

**macOS**:

```bash
bash install.sh
```

installer თვითონ აკეთებს ყველაფერს: პოულობს Python-ს, ქმნის ცალკე გარემოს,
აყენებს ბიბლიოთეკებს, ითხოვს გასაღებს (აკრეფისას არაფერი ჩანს — ასე უნდა იყოს) და
აკეთებს მალსახმობს. გაშვება მერე — `run.vbs` (Windows) ან `run.command` (macOS).

### exe-ს ან .app-ის თვითონ აწყობა

```powershell
.venv\Scripts\python.exe tools\build_app.py     # Windows -> dist\voice-typer.exe
```

```bash
.venv/bin/python tools/build_app.py                # macOS -> dist/voice-typer.app
```

**Mac-ის ვერსია მხოლოდ Mac-ზე აიწყობა** — Windows-ზე ვერ გააკეთებ, და პირიქით.

## ElevenLabs-ის API გასაღები

პროგრამა შენს ხმას ElevenLabs-ს უგზავნის ტექსტად გადასაყვანად. ამისთვის **შენი საკუთარი
გასაღები** სჭირდება — ჩემი ან სხვისი არ გამოდგება და არსად არ არის ჩაწერილი.

**ა) ანგარიში.** დარეგისტრირდი [elevenlabs.io](https://elevenlabs.io)-ზე. უფასო გეგმაც
გამოდგება საცდელად, მაგრამ Scribe-ის გამოსაყენებლად ბალანსი უნდა გქონდეს.

**ბ) გასაღების შექმნა.** გახსენი
[Settings → API Keys](https://elevenlabs.io/app/settings/api-keys) → **Create API Key**.

**გ) უფლებები — მნიშვნელოვანი ნაწილი.** გასაღები შეზღუდე, რომ მოპარვის შემთხვევაში
სხვა რამეს ვერ გამოიყენონ:

1. ჩართე **Restrict Key**
2. **Speech to Text** → **Access**
3. დანარჩენი ყველაფერი (Text to Speech, Speech to Speech, Voices და ა.შ.) → **No Access**
4. სურვილისამებრ: **Usage Limits** — თვიური ლიმიტი, რომ შემთხვევითი ხარჯი შეიზღუდოს
5. **IP allowlist არ შეავსო** — თუ შენი IP შეიცვალა, გასაღები მუშაობას შეწყვეტს

პროგრამა მხოლოდ ერთ მისამართს იყენებს — `POST /v1/speech-to-text`. სხვა უფლება არ სჭირდება.

**დ) დააკოპირე გასაღები.** ის მხოლოდ **ერთხელ** ჩანს, შექმნისთანავე. თუ დაკარგე,
ახალი უნდა შექმნა.

**ე) ჩასვი პროგრამაში.** პირველ გაშვებაზე აპლიკაცია თვითონ ითხოვს — ჩასვი ველში და
დააჭირე შენახვას. გასაღები `.env` ფაილში ჩაიწერება და მეორედ აღარ იკითხება.

თუ კოდიდან უშვებ და ხელით გინდა: დააკოპირე `.env.example` როგორც `.env` და ჩაწერე:

```
ELEVENLABS_API_KEY=sk_აქ_შენი_გასაღები
```

ბრჭყალები **არ** უნდა. ხშირი შეცდომებია: ცარიელი ადგილი `=`-ის გვერდით, კოპირებისას
დაკარგული ბოლო სიმბოლოები, ან სულ სხვა გასაღები, ვიდრე ის, რომელსაც საიტზე არედაქტირებ.

**ვ) შეამოწმე** (მხოლოდ კოდიდან გაშვებისას). ეს ბრძანება გეტყვის, რომელ მიმართულებას
სწვდება გასაღები. მნიშვნელობას არსად არ ბეჭდავს — მხოლოდ სტატუსებს:

```powershell
.venv\Scripts\python.exe tools\check_api_key.py
```

სწორად აწყობილი შეზღუდული გასაღები ასე პასუხობს:

```
GET  /v1/user            401  missing_permissions
GET  /v1/models          401  missing_permissions
GET  /v1/voices          401  missing_permissions
POST /v1/speech-to-text  OK
```

პირველი სამი „უარი" ნორმაა — პროგრამას ისინი არ სჭირდება. მთავარია ბოლო ხაზი.

> **`401 invalid_api_key` სულ სხვა პრობლემაა.** ეს ნიშნავს, რომ თვითონ გასაღები არ იქნა
> მიღებული — `.env`-ში არასწორი მნიშვნელობაა, ან გასაღები წაშლილია/გამორთულია საიტზე.
> უფლებების გადართვა ამას ვერ უშველის.

## პარამეტრები

ყველაფერი `config.json`-შია, კოდის შეხების გარეშე. ცვლილების შემდეგ პროგრამა გადატვირთე.

| პარამეტრი | ნაგულისხმევი | რას ნიშნავს |
| --- | --- | --- |
| `hotkey` | `f9` | რომელი ღილაკი იწყებს ჩაწერას |
| `hold_threshold_ms` | `400` | ამაზე დიდხანს დაჭერა = „გეჭირავს", ნაკლები = „დააჭირე" |
| `max_recording_seconds` | `300` | ავტომატური გაჩერება, რომ ჩარჩენილმა ღილაკმა ფული არ დახარჯოს |
| `min_recording_ms` | `300` | ამაზე მოკლე ჩანაწერი იგნორირდება — შემთხვევითი დაჭერა |
| `input_device` | `null` | მიკროფონი; `null` = სისტემის ნაგულისხმევი |
| `sample_rate` | `16000` | ჩაწერის სიხშირე; მეტყველებისთვის 16000 საკმარისია |
| `restore_clipboard` | `true` | ჩასმის შემდეგ ძველი clipboard დაბრუნდეს თუ არა |
| `clipboard_restore_delay_ms` | `300` | რამდენ ხანში დაბრუნდეს |
| `language_code` | `kat` | ქართული, ფიქსირებული — ავტოამოცნობა მოკლე ფრაზებზე ცდება |
| `model_id` | `scribe_v2` | ElevenLabs-ის მოდელი |
| `price_per_hour_usd` | `0.22` | ხარჯის დასათვლელი ტარიფი |
| `keyterms` | `[]` | სიტყვები, რომლებსაც ხშირად ამბობ და არასწორად იწერება |
| `prune_takes_after_days` | `7` | წარუმატებელი ჩანაწერები რამდენი დღის შემდეგ წაიშალოს |
| `window_scale` | `1.0` | ფანჯრის ზომა; `0.5` = ნახევარი. დიაპაზონი 0.3-2.0 |
| `content_scale` | `1.0` | წარწერებისა და აიქონების ზომა ფანჯრის ზომის ზემოდან. დიაპაზონი 0.6-1.5 |

არასწორი მნიშვნელობა გაშვებისთანავე იჭერს თავს — პროგრამა ამბობს რომელი პარამეტრია
გაფუჭებული და რა დიაპაზონია დასაშვები, და არ ეშვება ნახევრად გამართული.

### `keyterms` — სიზუსტის ერთადერთი ბერკეტი

თუ რომელიღაც სახელი ან ტერმინი მუდმივად არასწორად იწერება, ჩაამატე აქ:

```json
"keyterms": ["ნონიაშვილი", "ElevenLabs", "Claude Code"]
```

მაქსიმუმ 100 სიტყვა. მეტზე ElevenLabs ყოველ ჩანაწერს 20 წამად ითვლის და ფასი
რამდენჯერმე იზრდება — ამიტომ 100-ზე მეტი უარყოფილია გაშვებისთანავე, და არა ჩუმად მოჭრილი.

ElevenLabs Scribe v2 — დაახლოებით **$0.22 საათზე** ($0.004 წუთზე). ერთი წინადადება

რიცხვი `logs\usage.json`-შია.

## რა უნდა იცოდე

**ხმა კომპიუტერს ტოვებს.** ჩანაწერი ElevenLabs-ს ეგზავნება ტრანსკრიფციისთვის — სწორედ
ამიტომ მუშაობს ქართული ასე კარგად. ლოკალური Whisper ქართულს ცუდად ცნობს.

**არაფერი იკარგება.** ყოველი ჩანაწერი დისკზე ინახება გაგზავნამდე (`logs/pending/`) და
იშლება მაშინ, როცა მისი ტექსტი უკვე ფანჯარაშია. თუ ინტერნეტი გაწყდა, პროგრამა ჩაკვდა ან
გამორთე შუა პროცესში — მენიუში „ბოლო ჩანაწერის ხელახლა გაგზავნა" კვლავ იმუშავებს.
შეგიძლია მეორე წინადადება დაიწყო მაშინაც, როცა პირველი ჯერ იგზავნება — ერთმანეთს არ
გადააფარებენ.

**ტექსტი clipboard-ს გაივლის.** წამის მეასედში იქ იქნება, მერე ძველი შიგთავსი ბრუნდება.
სხვაგვარად ქართული ასოების ჩასმა ნებისმიერ პროგრამაში საიმედოდ არ გამოდის.

**ადმინისტრატორის უფლებით გაშვებული პროგრამები** ჩასმას არ მიიღებენ (Task Manager,
ზოგი ინსტალერი). ჩვეულებრივი პროგრამები და ბრაუზერები — ყველა მუშაობს. ეს დაცვაა და არა
ხარვეზი: პროგრამა ადმინისტრატორის უფლებას არ ითხოვს.

**რით განსხვავდება macOS.** სამი რამით: ჩასმა **Cmd+V**-ით ხდება Ctrl+V-ის ნაცვლად;
სისტემურ ზოლში (menu bar) ხატულა არ ჩნდება — ფანჯარა ისედაც ყოველთვის ხელმისაწვდომია;
და პროგრამა Accessibility-ის ნებართვის გარეშე საერთოდ ვერ მუშაობს.

**ტრანსკრიპტი ნედლია.** სასვენი ნიშნები ისეთია, როგორსაც Scribe აბრუნებს — დამატებითი
დამუშავება არ ხდება.

**ერთი ასლი ერთდროულად.** მეორედ გაშვება უარყოფილია — ორივე ჩაწერდა და ორჯერ გადაიხდიდი.

## თუ არ მუშაობს

`logs\voice_typer.log`-ში წერია რატომ. ხშირი მიზეზები:

| სიმპტომი | მიზეზი და რა ვქნა |
| --- | --- |
| „No ElevenLabs API key" | `.env` არ არსებობს ან ცარიელია — იხ. მე-3 ნაბიჯი |
| „401 invalid_api_key" | `.env`-ში არასწორი გასაღებია, ან საიტზე წაშლილია/გამორთულია |
| „missing the permission" | გასაღებს **Speech to Text** უფლება არ აქვს — შეზღუდვებში ჩართე **Access** |
| „429" | ElevenLabs ზღუდავს — ცოტა ხანში სცადე |
| ტალღა ბრტყელია ლაპარაკისას | მიკროფონი არ იწერს — შეამოწმე `input_device` `config.json`-ში |
| ტექსტი არ ჩნდება, მაგრამ Ctrl+V მუშაობს | აქტიური პროგრამა ჩასმას ბლოკავს — სავარაუდოდ ადმინისტრატორით გაშვებულია |
| „ჩასმა ვერ მოხერხდა — ტექსტი logs საქაღალდეშია" | clipboard დაკავებულია სხვა პროგრამით; ტექსტი `logs\last_transcript.txt`-შია |
| „ტექსტად გარდაქმნა ვერ მოხერხდა" | ინტერნეტი ან გასაღები — ჩანაწერი შენახულია, გამოიყენე „ხელახლა გაგზავნა" |
| ფანჯარა არსად ჩანს | ეკრანის კიდეს მიღმაა — წაშალე `logs\window.json` და გადატვირთე |
